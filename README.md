This project was cloned from [kcvinker/Winforms](https://github.com/kcvinker/Winforms). Flex layout was added, and new controls were introduced, including TabControl + TabPage, StatusBar, Panel, Splitter, etc. The listview supports sorting and virtual listview.
Try running “odin build app.odin -file” to compile demo.
All modifications were made by AI (yuanbao web version).
